## 📌 Objective
Design and implement an **interactive game powered by Computer Vision** to be showcased during the university open house. The target audience will be **6th-grade high school students**, so your game must be:

- 🎯 Fun and engaging  
- 👀 Visually clear and interactive  
- ⚡ Responsive in real-time  

You must integrate at least **one Computer Vision technique** studied in class:
- Object Detection  
- Image Segmentation  
- Object Tracking (e.g., KCF, CSRT, DeepSORT)  
- Gesture or motion-based interaction  
- etc.

---

## 🕹️ Game Requirements

### 1. Gameplay
- The game must be **easy to understand in < 30 seconds**
- Duration per play: **1–2 minutes max**
- Must include:
  - A clear goal (score, time, survival, etc.)
  - Feedback (score, sounds, visual cues)
  - Restart option

### 2. Interaction (Computer Vision)
The player must interact using **camera-based input**, for example:
- 🖐️ Control with hands (gesture recognition)
- 🧍 Body movement tracking
- 🎯 Object-based interaction (e.g., colored objects)
- 🧠 Face or pose-based control

### 3. Game Modes (choose one)
- **Single Player**
- **Optional - Split Screen (2 players competing)**

### 4. Technical Requirements
- Use Python (recommended with OpenCV, YOLO, Mediapipe, etc.)
- Real-time processing (≥ 15 FPS recommended)
- Stable detection/tracking (no excessive flickering)
- Clean UI (text, overlays, instructions)

---

## 💡 Example Ideas (Optional Inspiration)
- 🥊 *Punch the Targets*: hit virtual objects using hand tracking  
- 🎯 *Color Hunter*: find and capture colored objects  
- 🧍 *Avoid the Obstacles*: move your body to dodge virtual elements  
- 🏎️ *Gesture Racing*: control a car with hand gestures  
- ⚽ *Virtual Goalkeeper*: block balls using body tracking
